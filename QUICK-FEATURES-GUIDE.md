# 🚀 Quick Features Guide

## What's New?

### 1. ✏️ Edit Transactions
**Location:** Dashboard → Transactions tab → Click "Edit" button

**What you can edit:**
- Category
- Amount  
- Date
- Payment Method
- Type (Income/Expense)
- Description
- Notes

**How:**
1. Click "Edit" on any transaction
2. Modal opens with form
3. Make changes
4. Click "Save Changes"

---

### 2. ⚙️ Settings Page
**Location:** Sidebar → Settings (gear icon)

#### General Tab:
- Edit your name
- View account info
- See member since date

#### Preferences Tab:
- **Change Currency** (20+ options)
- USD, EUR, GBP, INR, JPY, and more!
- Applies across entire platform
- Saved to your account

---

## How to Change Currency

1. Click **Settings** in sidebar
2. Go to **Preferences** tab
3. Select currency from dropdown
4. Click **"Save Currency"**
5. Done! All amounts update instantly

**Available:** USD ($), EUR (€), GBP (£), INR (₹), JPY (¥), and 15+ more

---

## Quick Actions

### Edit a Transaction:
```
Dashboard → Transactions → Edit → Make changes → Save
```

### Change Currency:
```
Settings → Preferences → Select currency → Save
```

### Delete a Transaction:
```
Dashboard → Transactions → Delete → Confirm
```
